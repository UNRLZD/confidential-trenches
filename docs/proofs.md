# Proofs

Every money change in this repository counts as done only after a real run lands and each of its transactions reads back on chain. The run records live next to each change's live check in [scripts/live-checks/](../scripts/live-checks/), one `Tx: <chain> <id>` line per transaction. `node scripts/ci/money-gate.mjs --all` reads every one of them back on two public RPCs. The tables below are generated from those records.
